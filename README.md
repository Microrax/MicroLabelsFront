# MicroLabelsFront

This is a frontend web application built with **Angular** and styled using **Angular Material**. It serves as a management interface for handling **clients** and **labels**, providing seamless integration with a backend API developed in **.NET**.

## ✨ Features

- 🔄 **Add/Edit/Delete Clients**
- 🔖 **Add/Edit/Delete Labels**
- 🔗 **Assign Labels to Clients**
- 👁️ **Preview Label ZPL Code** via external API
- 🖨️ **Send Print Requests** to external printing API

## 🛠️ Technologies Used

- **Angular** (vX.X)
- **Angular Material**
- **.NET** (Backend API - not included in this repo)
- **ZPL Rendering API** (external service)
